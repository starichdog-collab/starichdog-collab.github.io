사용 방법직접 작성·다운로드작성 예시참고 자료

어떤 자료를 바꿨고 어떤 회신을 받았는지 남기세요

태양광 설계와 시공 준비 중 제품, 배치, 지지 위치 또는 기존 건물 자료가 달라지면 이전 자료와 새 자료를 구분할 필요가 있습니다. 이 페이지는 변경 전후의 도면·사양서와 담당자의 회신을 연결하는 기록 도구입니다.

구조계산서의 적용 범위와 재검토 필요 여부는 검토 담당자에게 확인하세요. 이 기록표에 ‘회신 받음’을 선택하는 것만으로 설계 적합성이나 시공 승인이 확정되지 않습니다. 먼저 구조계산서와 도면 대조 방법을 읽고 기록하면 편리합니다.

  1. 변경 제안기존·새 문서번호와 바뀐 부분을 적습니다.
  2. 확인 요청확인할 담당자에게 같은 자료를 전달합니다.
  3. 회신 연결조건·미결 사항과 반영 문서를 기록합니다.

도면 이름은 같아도 개정번호를 따로 기록하세요

예를 들어 기존 파일이 배치도_PV-01_R0.pdf, 새 파일이 배치도_PV-01_R1.pdf라면 두 파일을 모두 남기고 변경 이유를 적습니다. 담당자가 보완자료를 요청했다면 요청 내용과 회신 날짜를 같은 기록번호에 연결합니다.

가상 기록 CH-001
대상: A동 동측 배치
변경 제안: 기존 배치도 R0 → 제안 배치도 R1
질문: 기존 검토 자료 중 어느 문서를 갱신해야 하는지 확인 요청
상태: 검토 요청 / 회신 대기

이 예시는 문서관리 방법을 설명하기 위한 것이며 실제 수행실적이나 기술적 승인 사례가 아닙니다. 회신을 받으면 기술적 조건을 임의로 줄이거나 ‘완료’로 바꾸지 말고 원문과 연결해 두세요.

누락을 줄이는 기록 원칙

  • 한 기록번호에는 추적할 수 있는 하나의 변경 묶음을 적습니다. 서로 다른 구역이나 회신 대상이면 나누어 기록합니다.
  • 변경 전 파일을 보관하고, 새 파일에는 개정번호와 날짜를 표시합니다. 파일명만으로 판별되지 않으면 문서 표지 정보도 적습니다.
  • 회신 받은 날짜와 담당자, 남은 조건을 함께 적습니다. ‘자료를 보냈음’과 ‘회신을 받았음’을 구분합니다.
  • 최종 자료를 인계할 때 최신 도면·사양서와 변경 기록의 파일명이 맞는지 확인합니다.

공사 완료 시 받을 자료는 준공자료 인수인계 안내와 함께 정리하세요.

참고 자료와 양식의 성격

홍콩 전기기계공사서(EMSD)의 태양광 기록·문서 안내는 시스템 도면, 장비 기술자료와 인수인계 기록을 구분해 관리합니다. 이 페이지는 문서 관리의 구분을 참고해 두자가 만든 일반 기록 양식으로, 기술검토 결과나 법정 제출 서식을 대신하지 않습니다.
